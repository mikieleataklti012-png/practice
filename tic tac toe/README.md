# ❌⭕ Tic Tac Toe

A light, interactive, browser-based Tic Tac Toe game built using vanilla HTML, CSS, and JavaScript. 

---

## 🚀 Features

* **Custom Player Names:** Dynamic prompts allow players to enter custom names before starting.
* **Interactive Turn Tracking:** Visual status indicator displaying whose turn it is in real-time.
* **Smart Win & Draw Detection:** Automatic evaluation of all 8 winning combinations (rows, columns, diagonals) and draw state handling after every move.
* **Game Reset:** Built-in "Restart" functionality to dynamically rebuild the board and start a new round.
* **Responsive CSS Grid Layout:** Smooth 3x3 grid styling designed using modern CSS.

---

## 🛠️ Built With

* **HTML5** – Game structure and layout containers.
* **CSS3** – CSS Grid layout, button styling, and positioning.
* **JavaScript (ES6+)** – Factory functions, DOM manipulation, and event handling.
